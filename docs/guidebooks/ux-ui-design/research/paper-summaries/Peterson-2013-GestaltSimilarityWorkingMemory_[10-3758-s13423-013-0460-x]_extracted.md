# The Gestalt Principle of Similarity Benefits Visual Working Memory

## Study Overview
- **Citation**: Peterson & Berryhill, 2013
- **Study Type**: Experimental (two within-subjects lab experiments)
- **Sample**: Exp. 1: n=10 undergraduates (mean age 24.8); Exp. 2: n=13 undergraduates (mean age 22.5); total N=23
- **Task**: Visual change detection — briefly presented colored circles, maintenance period, then probe whether one circle changed color
- **DOI**: 10.3758/s13423-013-0460-x
- **PMID**: Not provided

## Key Findings

- **Finding 1 — Similarity improves VWM accuracy**: Grouping identical color items improved overall change-detection accuracy vs. ungrouped arrays.
  - Effect size: F(1, 9) = 50.08, p < .001, partial eta-squared = .85 (Exp. 1 — very large effect)
  - Accuracy: grouped M=.87 vs. ungrouped M=.75 (average across all set sizes)

- **Finding 2 — Similarity benefit scales with cognitive load**: The benefit of grouping was not constant across set sizes but grew as array size increased.
  - SS3: grouped=.97 vs. ungrouped=.95 (ns, p=.56)
  - SS4: grouped=.96 vs. ungrouped=.82 (p=.009)
  - SS6: grouped=.90 vs. ungrouped=.63 (p=.001)
  - Interaction F(2, 18) = 11.99, p < .001, partial eta-squared = .57

- **Finding 3 — Similarity requires proximity to benefit VWM**: Exp. 2 parametrically varied the distance between matching items. Only proximal identical items (neighbors, ~6° apart) improved VWM.
  - Similarity (proximal) vs. control: accuracy .74 vs. .65, capacity 2.82 vs. 1.82 — both p=.01
  - R1 (one intervening item, ~9° apart) vs. control: p > .30 (ns)
  - R2 (two intervening items, ~12° apart) vs. control: p > .30 (ns)
  - Overall condition effect: F(3, 36) = 4.21, p = .01, partial eta-squared = .26

- **Finding 4 — Grouped items show an encoding bias**: Performance benefits were driven specifically by trials where the probed item was previously part of a grouped pair, not by general improvement to all items. This suggests similar items are preferentially encoded as a chunk.
  - Grouped probe vs. ungrouped probe accuracy: .94 vs. .80, F(1, 9) = 34.87, p < .001, partial eta-squared = .80
  - Grouped probe RT: 1,910 ms vs. 2,215 ms for ungrouped probe, F(1, 9) = 11.21, p = .009

- **Finding 5 — Similarity boosts estimated VWM capacity**: Object-based capacity estimates (K) were higher in grouped conditions, especially at higher loads.
  - SS4: grouped K=3.64 vs. ungrouped K=2.62 (p=.01)
  - SS6: grouped K=4.70 vs. ungrouped K=1.76 (p=.001)
  - Main effect F(1, 9) = 55.96, p < .001, partial eta-squared = .86

- **Finding 6 — Participants were consciously aware of the grouping benefit**: Confidence ratings were significantly higher for grouped items.
  - Confidence (1–6 scale): grouped probe M=5.47 vs. ungrouped probe M=4.59, t(9)=5.82, p<.001

## Effect Sizes (Raw Values)

**Experiment 1:**
- Grouping main effect on accuracy: partial eta-squared = .85, F(1,9) = 50.08, p < .001
- Grouping main effect on RT: partial eta-squared = .40, F(1,9) = 5.90, p = .04
- Grouping main effect on confidence: partial eta-squared = .86, F(1,9) = 53.55, p < .001
- Grouping main effect on capacity (K): partial eta-squared = .81, F(1,9) = 38.52, p < .001
- Probe type (grouped vs. ungrouped) x set size interaction on accuracy: partial eta-squared = .57, F(2,18) = 11.99, p < .001
- Probe type x set size interaction on capacity: partial eta-squared = .74, F(2,18) = 24.94, p < .001

**Experiment 2:**
- Condition main effect on accuracy: partial eta-squared = .26, F(3,36) = 4.21, p = .01
- Condition main effect on capacity: partial eta-squared = .25, F(3,36) = 3.95, p = .02
- No effect on RT: F(3,36) = 0.33, p = .81

**Condition mean data (Exp. 1, accuracy):**
- SS3 grouped: .96 | SS3 ungrouped: .86
- SS4 grouped: .89 | SS4 ungrouped: .74
- SS6 grouped: .75 | SS6 ungrouped: .64

Note: No Cohen's d reported. All effects quantified via partial eta-squared from repeated-measures ANOVA.

## Mechanisms & Moderators

- **Mechanism — Encoding bias / chunking**: The similarity benefit appears at encoding, not retrieval. Grouped items are preferentially encoded as a "chunk," consuming fewer mnemonic slots. Ungrouped items in the same array did not benefit, ruling out a general attentional account.
- **Mechanism — Reduced neural requirements**: Consistent with Xu & Chun (2007) fMRI evidence showing grouped items produce lower-amplitude inferior IPS activation — grouped representations are neurally cheaper to maintain.
- **Moderator — Spatial proximity (critical)**: Similarity only benefits VWM when similar items are adjacent. Separation by even one intervening item eliminates the effect. Proximity is a necessary condition, not merely additive.
- **Moderator — Set size (load)**: The similarity benefit is negligible at SS3 (near ceiling) but grows substantially at SS4 and SS6. Grouping matters most under high cognitive load — exactly when designers need it most.

## Study Design Details

- **Stimuli**: Colored circles (8 colors), 200ms presentation, 1,000ms maintenance delay, single probe
- **Grouping**: Pairs of same-color circles in circular array; in Exp. 1 items were always adjacent; in Exp. 2 proximity was parametrically varied (adjacent / +1 intervening / +2 intervening / no repetition)
- **Control condition (Exp. 2)**: No items shared colors
- **Articulatory suppression**: Used throughout to block verbal rehearsal strategies
- **Set sizes tested**: 3, 4, and 6 items

## Limitations

- **Very small samples**: n=10 (Exp. 1) and n=13 (Exp. 2); all undergraduates. Effect sizes are very large (partial eta-squared .80+) but confidence intervals not reported. Results could be unstable.
- **Single feature dimension**: Similarity manipulated via color only. Whether the same proximity constraint applies to shape, size, or texture similarity is untested.
- **Artificial stimuli**: Colored circles in circular array. Ecological validity to real UI layouts (irregular grids, lists, icon groups) is assumed, not tested.
- **One-to-one grouping only**: Groups were always pairs of two identical items. Whether groups of 3+ produce stronger or weaker benefits is unknown.
- **Laboratory task specificity**: Change detection is a clean memory measure but differs from the scanning, scrolling, and decision-making in actual app use.
- **No replication in non-student populations**: Whether the effect holds for older adults or users under real task demands is unknown.

## Population Scope Assessment

- **Population**: Undergraduate students (mean age ~23)
- **Relevance to casual behavior change**: N/A — this is a perception/cognition study
- **Relevance to UX/UI design**: High. VWM is the primary bottleneck during visual scanning of interfaces. Findings directly inform grouping decisions in navigation, lists, icon grids, and any UI with repeated or categorized elements.
- **Red flags**: None for UX application. Not a clinical population. The proximity constraint is important — this is not a license to group by similarity anywhere regardless of layout.

## Conclusions

Grouping by color similarity benefits visual working memory, but only when similar items are spatially proximate. Proximity-plus-similarity improved change-detection accuracy by 9-12% and substantially increased estimated VWM capacity, especially at high set sizes. The authors conclude: "Similarity can be included in the list of Gestalt principles that facilitate VWM—namely, proximity, connectedness, and common region." The mechanism appears to be encoding-level chunking: similar proximal items are prepackaged into a single mnemonic unit, reducing VWM load. When similar items are spatially separated, no benefit materializes.

## Extraction Notes

**Usefulness for guidebook:** High. This paper gives clean experimental grounding for two common UX rules: (1) group related items visually by color/style, and (2) keep those groups spatially tight. The finding that grouping helps most at high load is particularly relevant — it means grouping matters more on dense UIs (settings screens, data tables, navigation menus) than on sparse ones.

**Key design implication:** Similarity grouping is not a "nice to have" aesthetic choice — it actively reduces the cognitive cost of scanning an interface. But the proximity constraint matters: giving items the same color while scattering them across a layout will not produce the memory benefit. Proximity + similarity must be paired.

**Comparison context from paper:** Similarity (12% benefit, Exp. 1) matches proximity alone (12% in Woodman et al., 2003) and exceeds connectedness alone (6%). This suggests color-coding by category is as effective a grouping cue as physical proximity, assuming proximity is already satisfied.

**Caution on effect size interpretation:** Partial eta-squared values (.80+) look enormous but come from n=10 within-subjects designs — these are not effect sizes that will fully replicate at scale. The directional finding (proximity required, load moderates benefit) is theoretically well-grounded and replicated across two experiments, giving reasonable confidence in the qualitative conclusion even if the magnitude overstates the true effect.
