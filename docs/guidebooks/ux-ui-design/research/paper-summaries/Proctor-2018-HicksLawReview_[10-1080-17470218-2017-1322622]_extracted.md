# Hick's Law for Choice Reaction Time: A Review

## Study Overview
- **Citation**: Proctor, R.W. & Schneider, D.W., 2018
- **Study Type**: Narrative/systematic review of empirical literature from 1952 to ~2017
- **Sample**: Review article; primary studies cited range from n=1 (Hick's original N=1–2) to hundreds of participants across reviewed work
- **Journal**: Quarterly Journal of Experimental Psychology, Vol. 71(6), pp. 1281–1299
- **DOI**: 10.1080/17470218.2017.1322622
- **Citation count**: Hick's original 1952 paper cited 1,163 times as of April 2017; 32–48 citations/year from 2006 to 2016

## Key Findings

- **Finding 1 — The core law**: Choice RT increases as a log-linear function of the number of equally likely stimulus-response alternatives. The accepted formulation is RT = a + b log2(n), where a is the intercept (baseline processing time), b is the slope (rate of information processing), and n is the number of alternatives. This relationship has been replicated extensively since Hick (1952) and Hyman (1953).

- **Finding 2 — S-R compatibility modulates the slope dramatically**: The slope of the Hick's law function varies substantially with stimulus-response compatibility. With highly compatible mappings (e.g., pressing the finger key that vibrates under it; saccadic eye movements toward stimulus location; spatially compatible joystick-cursor), set-size effects approach zero — RT is essentially flat across 2, 4, and 8 alternatives. With arbitrary or incompatible mappings, the slope is steeper. Dassonville et al. (1999) showed slope is an increasing function of mapping incompatibility.

- **Finding 3 — Practice reduces slope**: With practice, the slope relating RT to number of alternatives decreases. In Hale (1968), 8 vs. 2 choice RT difference was ~500 ms in session 1 but only ~300 ms in session 5 (1,000 trials/session). In Wifall et al. (2016), after ~4,000 practice trials, the 8 vs. 2 difference was reduced to 149 ms. Teichner & Krebs (1974) concluded that with sufficient practice, RT might become independent of set size entirely.

- **Finding 4 — Law holds for 2–10 alternatives; breaks down beyond ~8**: Multiple studies show Hick's log-linear function fits well for set sizes in the range 2–10 alternatives (limited partly by having 10 fingers). For very large set sizes (>10), results are mixed. Longstreth (1988) and Seibel (1963) found departures from the log-linear function at large set sizes, with Longstreth concluding Hick's law does not apply beyond ~8 alternatives (3 bits of information). However, Hilgendorf (1966) found the log-linear relationship extending to 1,000 alternatives for recognition time.

- **Finding 5 — Response set size > stimulus set size**: Wifall et al. (2016) disentangled stimulus and response set sizes using many-to-one mappings. Response set-size effect was larger than stimulus set-size effect, leading to a proposed amended equation: RT = a + bsHs + brHr (separate parameters for stimulus and response uncertainty).

- **Finding 6 — Hierarchical menu search supports broader shallower trees**: Landauer & Nachbar (1985) showed target selection through menu trees (integers/words from 4,096 items) was well fit by a logarithmic function rather than linear, supporting Hick's law. Conclusion: "Broader, shallower menu trees yield faster search than narrower, deeper ones."

- **Finding 7 — Sequential effects and repetition confound**: As set size increases, probability of stimulus-response repetition decreases (50% repetitions for n=2 vs. 25% for n=4 with unconstrained randomization). Since S-R repetitions are reliably faster than switches (well-replicated), part of the set-size effect may be an artifact of this confound rather than true information processing cost. Kornblum's (1968, 1969) work showed blocks with equal average information but different repetition probabilities produced different RTs, challenging the pure information-theoretic account.

- **Finding 8 — Contemporary models**: Evidence accumulation models (leaky competing accumulators) can produce Hick's law by raising response criterion logarithmically with set size to maintain constant error rates. The memory-based model (Schneider & Anderson, 2011) explains Hick's law via a context-based fan effect in memory retrieval combined with reduced repetition-based retrieval shortcuts at larger set sizes.

## Effect Sizes (Raw Values)

No meta-analytic effect sizes reported — this is a narrative review. Specific magnitude data from cited studies:

- **8 vs. 2 choice RT difference, session 1** (Hale, 1968): ~500 ms
- **8 vs. 2 choice RT difference, session 5 of 5** (Hale, 1968): ~300 ms (compatible mapping, 1,000 trials/session)
- **8 vs. 2 choice RT difference, post ~4,000 practice trials** (Wifall et al., 2016): 149 ms
- **Hick's law slope range**: 0 ms/bit (high S-R compatibility) to several hundred ms/bit (incompatible mappings)
- **Intelligence correlation**: Slope of Hick's law function correlates negatively with general intelligence; Jensen & Munro (1979) found r = −0.36 between slope and Raven's Progressive Matrices

No aggregate effect sizes with CIs are provided; this is expected for a theoretical/historical review.

## Mechanisms & Moderators

- **Primary mechanism**: Response selection bottleneck. When S-R alternatives must be retrieved from memory, RT scales logarithmically with set size (fan effect on memory retrieval). When responses are direct/reflexive (no memory required), the set-size effect disappears or reverses.

- **Moderator 1 — S-R compatibility**: High compatibility (natural/direct mapping) eliminates or greatly reduces the set-size effect. Low/arbitrary compatibility amplifies it.
  - Evidence: Leonard (1959) found no RT difference across 2, 4, and 8 choices for vibrotactile stimuli; Kveraga et al. (2002) found no effect for prosaccades but standard Hick's effect for antisaccades and keypresses.

- **Moderator 2 — Practice**: Extensive practice reduces slope toward (possibly) zero. Both declarative memory retrieval shortcutting (repetition checking) and compiled S-R procedures likely contribute.
  - Evidence: Hale (1968), Wifall et al. (2016); Teichner & Krebs (1974) review.

- **Moderator 3 — Memory demands**: Set-size effects occur when S-R associations must be maintained in memory. Effects are absent or minimal in situations that do not require memory for S-R alternatives (spatially direct movements, vibrotactile, prosaccades).
  - Evidence: Schneider & Anderson (2011) synthesis of null-effect literature.

- **Moderator 4 — Set size range**: The logarithmic relationship is empirically robust in the 2–10 range. Beyond 8–10, the function may flatten or diverge from log-linearity.

- **Moderator 5 — Stimulus vs. response set size**: Response set size drives more of the Hick's law effect than stimulus set size (Wifall et al., 2016).

- **Moderator 6 — Sequential dependencies (confound)**: Set-size effects are partly inflated by the confound between set size and S-R repetition probability. Studies controlling for this still find set-size effects, but the slope is attenuated.

## Limitations

- **Narrative (not systematic) review**: No formal inclusion/exclusion criteria or quality ratings. Selective coverage acknowledged ("We selectively review...").
- **No effect size pooling**: Cannot extract summary quantitative estimates; all numbers are from individual studies.
- **Publication date of primary studies**: Core boundary condition work is from the 1950s–1980s. Generalizability to modern interfaces (touchscreens, voice, AI-driven UI) is extrapolated, not empirically tested.
- **Original studies are low-N**: Hick's original work used 1–2 participants. Many classic studies have small samples by contemporary standards.
- **Ecological validity**: Most underlying studies use laboratory keypress or eye-movement tasks, not naturalistic interface interactions. Real-world menu selection involves visual search, familiarity, and other factors not captured by classic Hick's law paradigms.
- **S-R compatibility not always quantified**: The review discusses compatibility as a categorical moderator; actual effect magnitude by compatibility level not reported systematically.
- **No conflict of interest reported**: No funding received for this article.

## Conclusions

Hick's (1952) law — RT = a + b log2(n) — is one of the most robust empirical relationships in human performance research, replicated across decades and task modalities. The practical takeaway for designers is that increasing the number of choices predictably slows user decision time, with the relationship being logarithmic rather than linear. However, the law has important boundary conditions: it is substantially attenuated (or eliminated) when choices are spatially direct/reflexive, when users are highly practiced, and likely when choices are familiar and well-organized. For interface design, the law supports minimizing option counts and using hierarchical/progressive disclosure structures. "Broader, shallower menu trees yield faster search than narrower, deeper ones" (Landauer & Nachbar, 1985).

## Named Frameworks (if applicable)

- **Hick's Law (Hick-Hyman Law)**
  - Formula: RT = a + b log2(n)
  - Components: Intercept (a = baseline perceptual-motor time), slope (b = information processing rate), n = number of equally likely alternatives
  - Applied form: Any design decision that changes the number of choices visible/available to a user at once affects decision speed logarithmically
  - HCI instantiation: Menu breadth vs. depth tradeoffs, toolbar counts, navigation option counts, form field choice sets

## Extraction Notes

This is a theoretical/historical review, not a primary empirical study. No extractable effect sizes with CIs in the typical sense. Useful for the guidebook as the **authoritative scholarly summary of Hick's law** — it confirms the law is robust, names all key boundary conditions (compatibility, practice, set size range, memory demands), and provides the Landauer & Nachbar menu-tree finding directly.

Key design-relevant takeaways for guidebook:
1. The logarithmic, not linear, nature of the effect is important: going from 2 to 4 choices costs more than going from 10 to 12.
2. Familiar, well-mapped choices (like standard OS navigation patterns) may largely bypass the effect — do not overapply Hick's law to highly familiar interface elements.
3. Progressive disclosure (show fewer options initially, reveal more on demand) is mechanistically grounded in this law.
4. The "fewer choices = faster" principle applies most strongly to unfamiliar UI, arbitrary mappings, and first-time interactions — not to experts using muscle memory.

The review does not provide controlled experiments on digital UI specifically; it extrapolates from laboratory keypress/eye-movement research. The Landauer & Nachbar (1985) touch-menu study is the most directly relevant empirical HCI test cited.
