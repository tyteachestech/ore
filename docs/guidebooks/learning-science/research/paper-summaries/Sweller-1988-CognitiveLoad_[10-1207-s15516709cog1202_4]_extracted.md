# Cognitive Load During Problem Solving: Effects on Learning

## Study Overview
- **Citation**: Sweller, J. (1988)
- **Study Type**: Experimental + Computational Modeling (framework paper)
- **Sample**: n=24 (Year 10 students, age 15-16 years) in primary experiment
- **DOI**: 10.1207/s15516709cog1202_4
- **PMID**: Not available

## Key Findings

- **Finding 1**: Nonspecific goal group made significantly fewer reproduction errors on structural elements
  - Effect size: Not explicitly reported (Mann-Whitney U tests only)
  - Significant on: angle-position errors U(12,12)=29, side-value errors U(12,12)=27, side-position errors U(12,12)=41, solution errors U(12,12)=17.5 (all p<.05)
  - Sample: n=24 (12 per group)

- **Finding 2**: No significant difference in total time to solve 6 problems between groups
  - Effect size: F(1,22) = .17, p>.05
  - Sample: n=24
  - Note: "the probability of this occurring by chance is .016" (nonspecific group faster on all 6 problems)

- **Finding 3**: No significant difference in total mathematical errors between groups during problem solving
  - Effect size: F(1,22) = 0, p>.05
  - Sample: n=24

- **Finding 4**: Computational model showed means-ends strategy required more cognitive resources than nonspecific goal strategy
  - See Effect Sizes section for exact values from Table 2
  - Sample: Computational model (not human subjects)

- **Finding 5**: Significant linear trend in solution time across problems
  - Effect size: F(1,22) = 49.38, p<.05
  - Sample: n=24

- **Finding 6**: Significant linear trend in mathematical errors across problems
  - Effect size: F(1,22) = 19.97, p<.05
  - Sample: n=24

- **Finding 7**: Significant linear trend in reproduction time
  - Effect size: F(1,22) = 4.76, p<.05
  - Sample: n=24

- **Finding 8**: Owen & Sweller (1985) found conventional group made "4-6 times as many mathematical errors" per side calculated
  - Effect size: Not explicitly reported (no exact ratio given)
  - Sample: Multiple experiments (sample sizes not stated in this paper)

## Effect Sizes (Raw Values)

**Primary experiment (n=24) - Problem solving performance:**
- Time to solve 6 problems: F(1,22) = .17, p>.05
- Mathematical errors: F(1,22) = 0, p>.05
- Solution time linear trend: F(1,22) = 49.38, p<.05
- Mathematical errors linear trend: F(1,22) = 19.97, p<.05
- Group × problem interaction (solution time): F(1,22) = .01, p>.05
- Group × problem interaction (errors): F(1,22) = .37, p>.05

**Primary experiment (n=24) - Reproduction performance:**
- Reproduction time (total): F(1,22) = .01, p>.05
- Reproduction time linear trend: F(1,22) = 4.76, p<.05
- Group × problem interaction (reproduction): F(1,22) = 3.83, p>.05

**Mann-Whitney U tests for reproduction errors (n=24):**
- Segment-labelling errors: U(12,12) = 55, p>.05
- Angle-value errors: U(12,12) = 63, p>.05
- Angle-position errors: U(12,12) = 29, p<.05
- Side-value errors: U(12,12) = 27, p<.05
- Side-position errors: U(12,12) = 41, p<.05
- Solution errors: U(12,12) = 17.5, p<.05

**Mean reproduction error scores (Table 6, scores out of 5):**
- Conventional group: Segment-labels 2.9, Angle-value 3.6, Angle-position 2.4, Side-value 2.6, Side-position 1.6, Solution 3.4
- Nonspecific Goal group: Segment-labels 2.4, Angle-value 3.4, Angle-position 1.1, Side-value 1.3, Side-position 1.2, Solution 1.8

**Computational model (Table 2, 3-step equation chaining problem):**
- Average working memory: Conventional 15.5, Nonspecific Goal 14
- Peak working memory: Conventional 16, Nonspecific Goal 14
- Number of active productions: Conventional 4, Nonspecific Goal 1
- Number of cycles: Conventional 5, Nonspecific Goal 3
- Total number of conditions matched: Conventional 29, Nonspecific Goal 17

## Mechanisms & Moderators

- **Mechanism 1**: Selective attention
  - "In order to solve a problem by means-ends analysis, a problem solver must attend to differences between a current problem state and the goal state"
  - "In order to acquire a schema, a problem solver must learn to recognize a problem state as belonging to a particular category of problem states that require particular moves"
  - Evidence: Theoretical argument; no direct empirical test

- **Mechanism 2**: Limited cognitive processing capacity
  - "In order to use the strategy, a problem solver must simultaneously consider the current problem state, the goal state, the relation between the current problem state and the goal state, the relations between problem-solving operators and lastly, if subgoals have been used, a goal stack must be maintained"
  - Evidence: Computational model showing 4 productions vs 1, 29 vs 17 conditions matched

- **Moderator 1**: Problem structure (state space size)
  - "Many problems have extensive state spaces. An uncontrolled search of a space containing thousands of paths is clearly unlikely to be productive"
  - "Mathematics or mathematically based problems presented to students tend not to be of this type"
  - Evidence: Theoretical discussion; not empirically tested

## Study Design Details

- **Intervention (Conventional group)**: Trigonometry problems with specific goal (e.g., finding length of specific side). Required to reproduce previous problem's diagram and solution after solving.

- **Intervention (Nonspecific goal group)**: Same trigonometry problems but "Calculate the value of as many variables as you can" with two unnecessary sides marked. Required to reproduce previous problem's diagram and solution after solving.

- **Problem types**: Six trigonometry problems requiring two-step solutions. Ratio sequences: sine-cosine, sine-sine, cosine-cosine, cosine-tangent, sine-tangent, tangent-tangent

- **Control/Comparison**: Between-subjects design, 12 subjects per group

- **Follow-up period**: Single session; 6 problems solved sequentially with 5 reproduction phases (no reproduction after first problem)

- **Time limit**: 5 minutes per problem solution; no time limit on reproduction. "If on any problem the solution had not been obtained within 5 minutes, the experimenter provided the correct solution"

- **Blinding**: Not mentioned

- **Attrition**: None reported

## Limitations

- Small sample size (n=24, 12 per group)
- Single session design with no long-term follow-up
- Limited to trigonometry problems; generalizability to other domains unclear
- "All had been introduced previously to the sine, cosine, and tangent ratios" - not completely novel material
- Did not replicate prior studies showing performance advantages on primary task: "it should be noted that the previous studies did not use a secondary task"
- Computational model limited to equation-chaining problems: "Problems requiring the use of more sophisticated algebraic procedures such as simultaneous equations can not be solved by these productions"
- Model is "minimal" by design - "care had to be taken to ensure that the model's mechanisms (especially the means-ends mechanisms) were basic, with no possibly unnecessary features"
- No direct measure of schema acquisition: "Enhanced memory of these characteristics could provide some evidence of schema acquisition... Nevertheless, these may be prerequisites for schema acquisition"
- "Pencil and paper were used for both the problem solving and reproduction phases" - external memory aids available
- No significance level stated for p-values beyond "<.05" designation

## Population Scope Assessment

- **Population**: Students (Year 10, age 15-16, Sydney high school)
- **Relevance to casual behavior change**: Low
- **Red flags**: Educational context; mathematical problem solving is not analogous to habit formation or everyday behavior change. This is a cognitive learning study focused on schema acquisition, not a behavior change intervention.

## Conclusions

"Considerable evidence indicates that domain specific knowledge in the form of schemes is the primary factor distinguishing experts from novices in problem-solving skill. Evidence that conventional problem-solving activity is not effective in schema acquisition is also accumulating."

"Conventional problem solving activity via means-ends analysis normally leads to problem-solution, not to schema acquisition."

"If, as suggested here, conventional problems impose a heavy cognitive load which does not assist in learning, they may be better replaced by nonspecific goal problems or worked examples. The use of conventional problems should be reserved for tests and perhaps as a motivational device."

## Named Frameworks (if applicable)

- **Framework**: Cognitive Load Theory (this is the foundational paper; theory not explicitly named)
  - Components:
    - Working memory/cognitive processing capacity (limited)
    - Schemas (domain-specific knowledge structures)
    - Means-ends analysis (problem-solving strategy)
    - Schema acquisition (learning process)
  - Research alignment (apparent from text):
    - Working memory → production system working memory, short-term memory limits
    - Schemas → expert-novice differences in memory and problem-solving strategies
    - Means-ends analysis → backward-working strategy, goal-directed search
    - Schema acquisition → learning through problem solving (or lack thereof)

## Quotable Passages

> "The cognitive load imposed on a person using a complex problem solving strategy such as means-ends analysis may be an even more important factor in interfering with learning during problem solving. Under most circumstances, means-ends analysis will result in fewer dead-ends being reached than any other general strategy which does not rely on prior domain-specific knowledge for its operation. One price paid for this efficiency may be a heavy use of limited cognitive-processing capacity. In order to use the strategy, a problem solver must simultaneously consider the current problem state, the goal state, the relation between the current problem state and the goal state, the relations between problem-solving operators and lastly, if subgoals have been used, a goal stack must be maintained." (pp. 191-202)

> "The results conform to those obtained in more conventional dual task experiments with the cognitive load imposed by one task interfering with performance on the other. More excess capacity appears to be available after solving a nonspecific goal problem than a conventional problem." (pp. 985-989)

> "Conventional problem solving activity via means-ends analysis normally leads to problem-solution, not to schema acquisition. Both theoretical and practical implications flow from this conclusion... Goal attainment and schema acquisition may be two largely unrelated and even incompatible processes." (p. 1044-1050)

## Boundary Conditions & Population Caveats

- **Applies to**:
  - Novice learners in mathematics and mathematics-related domains
  - Equation-chaining problems (geometry, trigonometry, kinematics)
  - Problems with "limited state spaces which can be explored fully in a few minutes by anyone familiar with the problem-solving operators"
  - Initial learning phases where schema acquisition is the goal

- **Does NOT apply to**:
  - Expert problem solvers (who "eliminated the backward-working phase" and "began by choosing an equation which allowed a value for an unknown to be calculated")
  - Problems requiring simultaneous equations (model cannot solve these)
  - "Problems [with] extensive state spaces. An uncontrolled search of a space containing thousands of paths is clearly unlikely to be productive"
  - Testing/assessment contexts

- **Unknown/untested**:
  - Long-term retention effects
  - Transfer to non-mathematical domains
  - Effects with completely novel material (students had prior trigonometry knowledge)
  - Optimal instructional sequence
  - Individual differences in working memory capacity as moderators
  - Effects when external memory aids are unavailable
  - Comparison to worked examples (mentioned but not tested in this study)

## Extraction Notes

This is the seminal Cognitive Load Theory paper. It combines theoretical argument, computational modeling (PRISM production system), and one primary experiment (n=24).

CRITICAL METHODOLOGICAL NOTE: The primary experiment found NO significant differences on problem-solving performance (time, errors). Significant differences appeared only on the secondary task (memory for problem structure). The authors explain: "In the present experiment, it appears that most subjects allocated excess capacity to the second task resulting in the usual performance difference occurring on that task rather than the primary one."

The computational model provides theoretical support by showing means-ends analysis requires 4 productions vs 1 for nonspecific goals. However, this is a computational demonstration, not an empirical finding with human subjects.

Owen & Sweller (1985) results are cited for the "4-6 times as many mathematical errors" finding, but no exact statistics are provided in this paper for that study.

The paper does NOT report means with standard deviations or confidence intervals. Table 6 reports mean error scores (out of 5) without standard deviations. All significance tests use either F-tests or Mann-Whitney U tests with only p<.05 or p>.05 designations (no exact p-values).
