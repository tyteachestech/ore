# Group `editor`: notes, reader text, list focus, hints

- **F1** Notes: a note's own ⌘Z history is lost when an outside edit merges in, because the editor remounts on `key={notes.version}` (`apps/desktop/src/Notes.tsx`). Durable fix: apply the outside change into the live editor (ProseMirror transaction, `apps/desktop/src/editor/`) so its history survives, keeping `preserve.ts`'s rule that lines he did not edit stay byte-identical. Test headless in `apps/desktop/test/` (the note editor tests run there).
- **F6** Reader: the shown-text map (`apps/desktop/src/text.ts`) and core anchoring (`packages/core`) are two maps of one text. Find a concrete input where they disagree (a highlight anchors in core but lands elsewhere on screen, or the reverse): tables, math, code, footnotes, images with alt text, soft hyphens, NBSP, emoji. If you find one, test it and make the app use core's map (one implementation). If none, skip with the inputs you tried.
- **F547** Mac lists: Tab into a source list with no row current shows nothing focused until ↓ lights a row. Expected (Finder, Mail): focus entering the list makes the first (or last-current) row current and visible. Find the shared list component; test in `apps/desktop/test/`.
- **F548** `title=` on the icon picker's cells (`IconPicker.tsx`) and on a transcript's timestamps (`Reader.tsx`, "Play from here"): the rule is the app's Hint component (see `apps/desktop/CLAUDE.md`). Replace them, and add a check that finds a bare `title=` on interactive elements in `apps/desktop/src` if one does not already exist (look first: there may be an allowlist test).
