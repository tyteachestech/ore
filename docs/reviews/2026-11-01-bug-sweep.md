# Bug sweep, 2026-11-01

Six parallel sweeps (reader, Home/Settings/sidebar, iPhone, note + diagram editor, Review, core/CLI). Nothing removed under the purpose rule.

## Fixed

**Reader**
- Esc with Find open (focus in the page) left the source; now closes the find bar first.
- After the Finish quiz or a chapter recall, focus jumped into the source note; it returns to the source.
- Done could run twice (Esc/× while saving), appending the note line twice and firing two toasts.
- Ask "Use this card" left an unhandled rejection on a failed save.

**Home, Settings, sidebar**
- Undo + redo toasts for collection rename / Move up / Move down, inline skill rename, clearing a skill goal.
- Esc during an add no longer swallows its failure.
- Done list empty state named ⌘↵; now reads the finish-source key (⇧⌘↵).
- Empty library Home shows the add line (⌘N / drop files), not just the ring.
- Icon picker arrow keys scroll the active icon into view.
- Random emoji / icon buttons use `<Hint>`, not `title=`.

**Review**
- A late AI grade or passage could land on the next card (and log its ai_rating there).
- "All caught up · today counts" on an off day.
- Gem overflow "+N" counted wrong.
- "All caught up" hid waiting cards (daily new limit, or cards in skills not picked); now says what waits.
- ⌘Z undoes a run of ratings, also from an empty Explain field.
- Quick quiz Keep going reviews every skill, like the main window.
- `ore today` shows new cards waiting and the daily limit.

**Editors**
- Deleting the block between two lists merged them into one on save (preserve.ts).
- An edit typed and undone back to the original never saved.
- Fenced code counted as headings and backlinks (links.ts, doctor).
- Diagram: a second Esc/Done while saving inserted the link twice; a failed save no longer follows an element link; renaming an unsaved diagram onto an existing name is refused.

**Core / CLI**
- Doctor/index showed `frontmatter invalid: [`; now the readable field error.
- AI adapter errors: Codex JSON event lines unwrapped, sign-in hint on every claude path, timeout and empty-output messages.
- Unknown flags and positionals name themselves and point at `--help`.
- Markdown files with YAML frontmatter (Obsidian, Jekyll): frontmatter feeds title/author/date instead of showing as text (fixture + tests).
- `.DS_Store` / `._*` refused as sources; no-extension binaries explained.
- Empty integer flags refused; `explain --start abc` checked; empty `ore ls` says what to do.

**iPhone**
- ⋯ › Skills submenu opened off screen; now a bottom sheet.
- Menu rows, highlight popup buttons and the prequestion header raised to 44pt.
- Key points tick from the whole row.
- Check on the phone says it runs on the Mac, instead of offering a retry that can't work.
