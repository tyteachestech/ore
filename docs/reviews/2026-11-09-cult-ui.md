# Cult UI for Ore (2026-11-09)

Tyler: "test using Cult UI to enhance the UI/UX", linking the AI SDK Agents MCP page. I went through all 307 items in Cult UI's registry (`bunx --bun shadcn@latest search @cult-ui`, MIT, already in `components.json`) and looked for places where one would help him learn. I checked each against the purpose rule, D129 (colour only for intents, 8-bit only where it means something) and D120.

**The linked registry is out.** AI SDK Agents' "AI Components" (aisdkagents.com, `@aisdkagents`) need a paid plan ($199 to $299) and a token. Their pages name no open-source license, so D120 rules them out the same way it rules out tldraw. Cult UI itself is MIT and free, so it is the registry used here.

**Most of Cult UI is decoration.** The Halo set, gradient rims, Border Beam, the glass, texture, shader and neumorph pieces, the heroes, illustrations and device mockups all fail D129. Polls, votes, the kanban and the dock have no place in Ore. Prompt Library and AI Instructions don't fit either, because Ore's prompts are versioned in core and he never edits them. Rolling Number shows counts, which the purpose rule rules out. Family Drawer is already the idea behind D155. What is left are a few interaction ideas. Each one is rebuilt in Ore's tokens, since Ore has no Tailwind.

| # | Cult UI piece | Where in Ore | What it does for him |
|---|---|---|---|
| 1 | Speech Bubble | The owl (D160) | **Built as D159.** A reply that lands while the tutor is closed comes out of the owl as its first lines, and a click opens the tutor there. He can look away during the 10 s wait and get the answer while the question is still on his mind. |
| 2 | Morph Surface / Dynamic Island | Owl → floating tutor | On a click, the owl's circle grows into the floating tutor and shrinks back into it on close, as Notion AI's button does. This shows that the tutor lives in that corner and that closing it keeps the chat. ⌘J would open it without motion (a keyboard action). |
| 3 | Popover Form | The tutor's + Card | + Card opens into the card's question, which he can reword before he keeps it, then shows the same "Card added" state. A card in his own words is easier to recall (the generation effect), and today + Card keeps the AI's wording as it is. |
| 4 | Prompt Composer's send ↔ loading swap | The tutor's field | While a reply is being written, the send arrow becomes a stop square, as in ChatGPT and Claude. Stop keeps whatever has come in and frees the field. Today a badly asked question costs 10 s and can't be taken back. Cult UI's composer has no stop of its own, so this copies its swap, not its look. |
| 5 | Text Animate / Typewriter | Tutor streaming (D138) | The streamed reply comes in at an even pace instead of in bursts, as ChatGPT smooths its own. That lets him read along without the text jumping. The cost: the last words land about 300 ms later, and the motion runs on an action he does often, so only build it if it reads calmer. |

Build order if he wants more: 4 (stop), then 3 (own-words card), 2 and 5 last (motion only).
