## How to repeat it
- WebKit in the cloud: from `apps/desktop`, `bunx playwright install webkit && bunx playwright install-deps webkit`, then the mock as `scripts/mock/README.md` says; the phone build is `ORE_PHONE=1 ORE_PHONE_LIBRARY=<seed> bunx vite`.
- The installed app: grant computer use to `com.tylerpoelking.ore` by bundle id (the name "Ore" resolves to the phone app's bundle), then list menus and capture the window with the background tools, which leave his screen alone.
